# HTTPS для резервного сервера (для браузерной версии)

Браузер не пускает запрос со страницы `https://` на обычный `http://` сервер.
Чтобы резерв работал прямо из браузера, ему нужен защищённый адрес.

Ниже три способа. Начните с того, который подходит вашей сети.

---

## Вариант A. Защищённый режим без интернета (закрытая сеть)

Подходит, когда интернет на резервном ПК ограничен и туннель не подключается.
Ничего скачивать не нужно — сертификат создаётся сам.

1. Остановите сервер (`stop.bat`).
2. Запустите **`https\secure.bat`**.
3. В окне появится адрес вида `https://192.168.1.50:8800/`.
4. **Один раз на каждом рабочем ПК** откройте в браузере адрес проверки
   (`https://192.168.1.50:8800/health`). Браузер предупредит о сертификате —
   нажмите «Дополнительно» → «Перейти на сайт». Должен появиться ответ `ok`.
5. Впишите адрес из пункта 3 в админ-панель и нажмите «Проверить связь».

Шаг 4 обязателен: без него браузер будет молча отклонять запросы.
Сертификат выдан на 10 лет, повторять не придётся.

---

## Вариант B. Туннель через интернет

Не требует настройки браузеров, но нужен свободный выход в интернет.

1. Сервер должен быть запущен (`run.bat`).
2. Запустите **`tunnel.bat`**. Первый раз скачается программа (~50 МБ).
3. Скопируйте появившийся адрес `https://…trycloudflare.com` в админ-панель.

Окно туннеля не закрывать. При перезапуске адрес меняется.

**Если в окне бесконечно повторяется `Failed to dial a quic connection`** —
сеть предприятия блокирует туннель. Файл уже переведён в обходной режим
(`--protocol http2`); если и он не проходит, используйте **вариант A**.

---

## Вариант C. Постоянный адрес на своём домене

Если у предприятия есть домен (например `mine.ru`) и аккаунт Cloudflare:

```
cloudflared.exe tunnel login
cloudflared.exe tunnel create pvs-backup
cloudflared.exe tunnel route dns pvs-backup calc.mine.ru
cloudflared.exe tunnel run --url http://127.0.0.1:8800 pvs-backup
```

В админ-панели указывается `https://calc.mine.ru/`. Адрес постоянный.

Если в сети есть свой nginx и сертификат предприятия — используйте
готовый образец `nginx.conf.example` из этой папки.

---

## Самый простой путь

Если резерв нужен только на аварийный случай — работайте с ним из
**десктопной версии** программы: там ограничение браузера не действует,
обычный адрес `http://IP:8800/` работает сразу.
