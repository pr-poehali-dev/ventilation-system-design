# Резервный сервер на хостинге Beget

Самый практичный вариант резерва: постоянный адрес, доступный из любой точки
России, свой SSL-сертификат, обновление одной командой. Не зависит от питания
офисного ПК и политики сети предприятия.

---

## Что понадобится

- Аккаунт Beget с поддержкой Python (тариф от «Blog» и выше)
- Домен или бесплатный технический адрес вида `логин.beget.tech`
- Доступ по SSH (включается в панели Beget за минуту)
- Репозиторий проекта на GitHub (Скачать → Подключить GitHub)

---

## Шаг 1. Создать сайт

Панель Beget → **Сайты** → «Добавить сайт» → имя, например `pvs-backup`.
Затем **Домены** → привязать домен или технический адрес к этому сайту.

## Шаг 2. Включить Python-приложение

Панель Beget → **Сайты** → у нужного сайта кнопка **«Приложения»** →
выбрать **Python** → версия **3.11** (или ближайшая доступная).

Beget создаст структуру и будет запускать приложение через Passenger:
он ищет файл `passenger_wsgi.py` в корне приложения.

## Шаг 3. Загрузить программу

Панель Beget → **SSH** (или подключиться терминалом) и выполнить:

```bash
cd ~
git clone https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git pvs-backup
cd pvs-backup
python3 backup-server/prepare.py
cp backup-server/beget/passenger_wsgi.py .
cp backup-server/beget/update.sh .
chmod +x update.sh
```

Установить библиотеки:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install --upgrade pip
pip install -r backup-server/requirements.txt
```

## Шаг 4. Указать Beget на папку приложения

В настройках Python-приложения укажите каталог `~/pvs-backup`
(там, где лежит `passenger_wsgi.py`) и файл запуска `passenger_wsgi.py`.

Перезапуск приложения — всегда так:

```bash
mkdir -p ~/pvs-backup/tmp && touch ~/pvs-backup/tmp/restart.txt
```

## Шаг 5. Включить SSL

Панель Beget → **Домены** → у домена → **SSL** → Let's Encrypt (бесплатно).
Через несколько минут сайт откроется по `https://`.

## Шаг 6. Проверить и подключить

Откройте в браузере:

```
https://ваш-домен/health
```

Должен появиться ответ со словом `ok` и списком расчётов.

Затем в программе: **Админ-панель → Сервер расчёта → Адрес аварийного
сервера** впишите `https://ваш-домен/` → «Проверить связь» → «Сохранить».

## Обновление программы

Когда основная программа обновилась, на Beget достаточно одной команды:

```bash
bash ~/pvs-backup/update.sh
```

Скрипт сам загрузит свежую версию из GitHub, обновит расчётные модули,
доставит библиотеки и перезапустит приложение.

Порядок работы: правки вносятся в основном проекте → код уходит в GitHub →
на Beget запускается `update.sh`. Резерв всегда совпадает с основной версией.

### Автоматическое обновление по расписанию

Панель Beget → **Планировщик задач (Cron)** → добавить задание,
например раз в неделю в 4 утра:

```
0 4 * * 1 bash ~/pvs-backup/update.sh >> ~/pvs-backup/update.log 2>&1
```

Тогда резерв будет обновляться сам.

---

## Если что-то не работает

| Признак | Причина и решение |
|---|---|
| «500 Internal Server Error» | Смотрите лог: `tail -50 ~/pvs-backup/tmp/*.log` или раздел «Ошибки» в панели. Обычно не установлены библиотеки — повторите шаг 3 |
| Страница `/health` не открывается | Приложение не перезапущено: `touch ~/pvs-backup/tmp/restart.txt` |
| «Расчётный модуль не найден» | Не выполнен `python3 backup-server/prepare.py` |
| Программа не видит сервер | Проверьте, что адрес начинается с `https://` и включён SSL |
| `git clone` просит пароль | Репозиторий закрытый — сделайте его публичным либо добавьте ключ доступа |

## Почему это лучше второго аккаунта в облаке

- Полный контроль: сервер ваш, лимитов вычислительного времени нет
- Постоянный адрес и настоящий SSL-сертификат
- Обновление одной командой либо автоматически по расписанию
- Стоимость хостинга уже оплачена
