# Аварийный расчётный сервер ПВ-Системы

Второй ПК, который считает то же самое, что и основной сервер. Включается,
когда на основном закончилось вычислительное время или пропала связь.

## Что нужно на втором ПК

- Windows 10/11 или Linux
- Python 3.11 (python.org, при установке отметить «Add python.exe to PATH»)
- Постоянный IP в сети предприятия (или проброшенный порт наружу)

## Установка (5 минут)

1. Скопируйте на второй ПК всю папку `backup-server` (вместе с `functions`).
2. Windows — двойной клик по `start.bat`.
   Linux — `sh start.sh`.
   Первый запуск занимает 2–3 минуты: ставится окружение и зависимости.
   Нужен интернет только на этот раз.
3. Окно должно показать список расчётов со статусом `OK`.
4. Дальше сервер можно запускать быстрее — файлом `run.bat`.

Если окно закрылось с ошибкой — запустите `start.bat` ещё раз: он покажет
причину и не закроется.

Сервер слушает порт **8800**. Другой порт: `python server.py --port 9000`.

## Проверка

С любого рабочего ПК откройте в браузере:

```
http://<IP-второго-ПК>:8800/health
```

Должен вернуться ответ со `"ok": true`.

## Подключение в программе

Панель администратора → **Сервер расчёта**:

- **Адрес аварийного сервера (URL)**: `http://<IP-второго-ПК>:8800/`
- **Автоматически переходить на резерв** — оставить включённым
- **Активный сервер**: «Основной» (резерв подхватится сам при сбое)
  или «Аварийный резерв», если нужно перевести всех принудительно.
- **Сохранить** — все рабочие места подхватят настройку автоматически.

## Важно про адрес

- Программа открыта по `https://` — браузер не пустит запрос на `http://`.
  В этом случае поставьте перед сервером HTTPS-прокси (nginx + сертификат)
  либо пользуйтесь резервом из десктопной версии.
- Проверьте, что порт 8800 открыт в брандмауэре Windows
  (Правила для входящих → Создать правило → Порт → TCP 8800 → Разрешить).

## Обновление расчётов

После обновления основной программы выполните в корне проекта:

```
python backup-server/prepare.py
```

и скопируйте обновлённую папку `functions` на второй ПК.

## Управление сервером (Windows)

| Файл | Что делает |
|---|---|
| `start.bat` | Первая установка и запуск (нужен интернет) |
| `run.bat` | Обычный запуск, когда всё уже установлено |
| `stop.bat` | Остановить сервер |
| `autostart.bat` | Включить/выключить автозапуск вместе с Windows |

`autostart.bat` работает как переключатель: первый запуск — автозапуск включён,
повторный — выключен.

## Ручное переключение серверов

В панели администратора, вкладка «Сервер расчёта», вверху есть кнопка
«Переключить на резерв» / «Вернуть на основной». Нажатие применяется сразу,
все рабочие места подхватывают изменение автоматически.
